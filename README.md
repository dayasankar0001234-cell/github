### Project Description
Biscuit Hub is a fun web app that predicts how long a biscuit can survive when dipped in hot tea using image analysis.
It turns biscuit dipping into a hilarious “engineering” experiment with survival time, dip limits, and tea-resistance ratings.

### The Problem (that doesn't exist)
